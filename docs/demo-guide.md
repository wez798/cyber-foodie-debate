# 5–8 分钟演示指南

## 演示前准备

1. 按 [README](../README.md) 安装依赖。准备一个隔离浏览器、两个测试账号 A/B，不使用个人资料、真实聊天或生产数据库。
2. 有真实服务授权时，配置有效 LLM Key 与 PostgreSQL 并完成迁移。没有授权时运行 `python scripts/run_demo.py`，前端使用专用 `cfd_demo_csrf` Cookie，按 README 启动；明确告知观众“固定回复，音频是测试提示音”。不要把它称为真实 AI 或语音成功。
3. 检查后端 `/health/live`、`/health/ready` 和前端首页。默认地址为 `http://localhost:5173`，Compose 前端为 `http://localhost:3000`。保持主机名一致。
4. 预先给 A 准备一个超过 50 条消息的测试会话，例如在离线云端聊天发送 26 轮。给会话取可辨认的话题，便于展示“加载更早消息”。演示脚本每次重启会清空自己的临时库，需要重新准备。
5. 清理仅属于演示的数据，准备一个待导入的游客完整问答。截图仅展示测试内容；不拍摄 `.env`、Cookie、开发者工具认证信息或密码框。

## 推荐顺序（约 7 分钟）

| 时间 | 操作 | 预期结果 |
| --- | --- | --- |
| 0:00–0:40 | 首次进入，介绍“自由聊/辩论赛”和登录入口；游客问“预算 20 元午饭怎么选” | 流式文字出现，标记游客本地保存；离线回复明确标注固定样例 |
| 0:40–1:30 | 注册测试账号或登录 A，点击“保存当前本地会话” | 用户主动确认后导入，云端读取核对成功，打开同一会话；满足锁与快照条件才清理本地副本 |
| 1:30–2:15 | 云端发送消息，刷新 `/chat/:id`，打开另一历史会话 | 恢复最近页，不串会话；登录页头显示 A |
| 2:15–3:20 | 打开已准备的长会话，点击“加载更早消息”；归档 → 已归档 → 恢复 | 更早消息插入且最近消息保留，归档可找到并恢复。删除另一个无用测试会话并确认，它不再可打开 |
| 3:20–4:50 | 切换辩论，填口味/预算/忌口，开始三轮 | 双方各三次发言与结构化裁决可见；真实模式内容取决于模型，离线模式不评判推荐质量 |
| 4:50–5:20 | 点击播放语音战报 | 真实模式应朗读；离线模式仅播放半秒测试音，证明音频下载与播放器可用 |
| 5:20–6:10 | 发起请求后取消；退出 A，再登录 B | 取消反馈明确，可以继续；B 不显示 A 的云端历史。游客未导入副本属于浏览器本地数据，不等同于 B 的云端记录 |
| 6:10–7:00 | 展示手机宽度下导航、表单与主要按钮，说明测试与限制 | 没有横向遮挡，核心操作可完成；展示交付报告中的实测与未实测范围 |

## 网络或服务失败时

- LLM 失败：展示真实错误提示，不解释为“生成成功”；恢复网络后重试，或另启离线演示明确切换模式。不要填造假模型结果。
- 语音失败：保留文字裁决，说明外部语音服务不可用，继续演示“再来一场”。离线脚本加 `--tts-fail` 可复现该路径；重启会丢弃本次演示数据。
- 导入失败或账号变化：本地副本应保留。核对当前账号后重新确认，不重复创建手工副本或清 localStorage 来隐藏错误。
- 分页失败：已加载内容保留，重试当前页。数据库不可用时先查看 readiness 和后台日志，不执行清库命令。
- 辩论结果在刷新或重启后不可恢复，这是已声明的内存存储限制；需要重新发起。云端聊天可在迁移正确的持久化数据库中恢复。

演示结束后关闭本次离线进程和测试标签页，恢复前端环境变量；不要删除共享数据库卷。真实服务验收、Docker/生产刷新结果以 [交付报告](final-delivery.md) 为准。
