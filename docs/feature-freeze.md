本轮面向短期工程实践交付。下一轮只做验收、必要缺陷修复与交付材料；不新增账户安全中心、邮件验证、密码找回、OAuth、管理员后台、Redis 或辩论持久化。

## 云端历史使用

“最近会话”显示未归档会话；“已归档”显示归档会话，可打开、恢复或删除。恢复后在“最近会话”查看。删除仍需确认且不可撤销。

复用 `GET /api/v1/conversations?limit=50&include_archived=true`，在返回页中筛选 `archived_at`；若本页无归档但还有游标，提示用户继续加载。每次点击最多读取一页，不自动扫描全部会话。恢复复用 `PATCH /api/v1/conversations/:id` 的 `{ "archived": false }`。无新增后端接口、Schema 或数据库迁移。

切换筛选或离开账号时取消旧列表与操作；迟到响应不能导航或更新当前列表。操作等待期间禁用重复提交，失败保留会话并可重试。
