## 技术亮点
- **Prompt 工程**: 使用 RTCO 结构化模板，角色设定 + 输出格式约束
- **防御性编程**: LLM 响应 JSON 解析失败时自动 fallback 到默认结果
- **上下文管理**: 辩论历史动态注入 Prompt，避免信息丢失
